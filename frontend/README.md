# Frontend (React SPA)

Source portal + admin. **Bukan** runtime production.

```bash
npm install
npm run dev      # http://localhost:5173 (proxy API → :8000)
npm run build    # → ../backend/public/spa/
```

Env: salin `.env.example` → `.env` (`VITE_R2_PUBLIC_URL`, `VITE_R2_FOLDER_PATH`).

Deploy: [../docs/DEPLOY.md](../docs/DEPLOY.md)
